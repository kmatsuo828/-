## 5. 環境の違い（なぜPCへ移すのか）

このセッションは Anthropic のクラウドコンテナ。ユーザーのPCではない。

| | クラウド実行（このセッション） | PCの Claude Code |
|---|---|---|
| Gmail添付の実体ダウンロード | **不可**（MCPに添付取得RPCが無い） | 可 |
| Claude in Chrome | **なし** | あり（要確認） |
| G:ドライブ / ローカルファイル | マウントなし | あり |
| Obsidian vault（`C:\Users\kmats\Desktop\second-brain`） | **不可** | あり |
| `*.supabase.co`（商品マスタ・在庫の照会） | **遮断**（CONNECT 403） | 可 |
| メーカーサイト（`inaba-denko.com` 等） | **遮断**（トンネル失敗） | 可 |
| Gmail / Drive の MCP連携 | 可（検索・本文・ファイル読取） | 可 |
| ブラウザ（Chromium+Playwright） | あり（ローカル配信のポータルは操作可） | — |

遮断の原因はサイト側ではなく送信元プロキシの許可リスト。詳細は `CLAUDE.md`。
