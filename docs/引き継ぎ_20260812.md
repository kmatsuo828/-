## 5. 環境の違い（なぜ移行が必要か）

このセッションは `environment_kind: anthropic_cloud`、`origin: ios`。
Anthropic のクラウドコンテナで動いており、ユーザーのPCではない。

| | クラウド実行（このセッション） | Coworkデスクトップ |
|---|---|---|
| Claude in Chrome | **なし** | あり |
| Gmail添付のダウンロード | **不可** | 可（Chrome UIの「ドライブに保存」） |
| G:ドライブ | マウントなし | あり |
| `*.supabase.co` | 遮断（商品マスタ照会不可） | 可 |
| メーカーサイト | 遮断 | 可 |
| Gmail / Drive の MCP連携 | **可**（検索・本文・ファイル読取） | 可 |
| ブラウザ（Chromium+Playwright） | あり（ローカル配信のポータルは操作可） | — |

Gmail MCP には添付の実データを返す RPC が無い（16ツール全確認済み）。
`gmail-attachment-organizer` スキルが Chrome UI を使っているのはこのため。
